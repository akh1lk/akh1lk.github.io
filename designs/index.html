Notes on the build

Every page is a single self-contained HTML file — no frameworks, no external requests, no font CDNs. Typography uses system faces that render natively on macOS (SF Mono, Helvetica Neue, Avenir Next, Didot, Phosphate, PT Mono) with fallbacks.

All ten are responsive, keyboard-accessible, and respect prefers-reduced-motion. Files live in designs/; open one directly in a browser or serve the folder.
